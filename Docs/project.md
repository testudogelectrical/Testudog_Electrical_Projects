# Project Information
This project is an LCD Display which displays current / voltage output from Testudog

* The ability to display current / voltage is handled by a button
* Extraction of voltage / current is handled by the INA226 
* Converting the voltage / current to display digits is handled by the Teensy4.1
* The 7-Segment Displays are used for the display
